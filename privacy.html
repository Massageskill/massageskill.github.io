Privacy Policy – Story Agent

Last updated: 17 October 2026

What the app does

Story Agent is a personal tool run on the owner's own computer. It generates videos and uploads them to the owner's YouTube channel through the YouTube Data API v3.

Data accessed

The app requests only the youtube.upload permission. It uses it solely to upload videos and set thumbnails on the channel of the account that signed in. It does not read, store or share any other Google user data.

Storage

The sign-in token is stored only on the owner's computer. No data is sent to any server other than Google's own APIs.

Sharing

No user data is sold, shared or transferred to third parties.

Revoking access

Access can be removed at any time from https://myaccount.google.com/permissions. Use of the YouTube API is also subject to the YouTube Terms of Service and the Google Privacy Policy.
